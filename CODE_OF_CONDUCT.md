# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful, assume good faith, keep discussions about the work, and do
not harass anyone. Aviation data can identify individuals' aircraft; do not use this project or
its issue tracker to track, expose, or target people.

Report unacceptable behaviour to the maintainer through a private GitHub message or the security
contact in [SECURITY.md](SECURITY.md). Reports are handled confidentially.
